# Публикация Perekup Market

Игра требует сервер Node.js, постоянное соединение SSE и постоянный диск для SQLite. Обычный статический хостинг вроде GitHub Pages для неё не подходит.

## Рекомендуемый вариант: Railway

1. Создать пустой репозиторий на GitHub и загрузить в него содержимое папки `perekup-market`.
2. В Railway выбрать `New Project` → `Deploy from GitHub repo` и указать репозиторий игры.
3. После создания сервиса открыть его настройки и добавить `Volume`.
4. Указать точку подключения тома: `/data`.
5. В `Variables` проверить переменную `PEREKUP_DATA_DIR=/data`. В Docker-образе она уже задана, вручную менять её обычно не требуется.
6. В разделе `Networking` нажать `Generate Domain`.
7. Открыть выданный адрес вида `https://имя.up.railway.app` и проверить регистрацию двух игроков.

Важно: без Volume база будет находиться во временной файловой системе и может исчезнуть при следующем развёртывании. Один сервер должен иметь ровно один подключённый том `/data`.

## Перенос текущих аккаунтов

В рабочей версии база находится в `data/game.db`. Она намеренно исключена из Git и Docker-образа, чтобы публичная публикация не раскрывала локальные аккаунты и PIN-хеши.

Для нового публичного сервера безопаснее начать с чистой базы. Если потребуется перенести текущий прогресс, нужно отдельно загрузить `game.db` в корень Railway Volume `/data` до первого публичного запуска.

## Проверка после публикации

- Главная страница должна отвечать по HTTPS.
- `https://ваш-домен/api/health` должен вернуть JSON со `status: "ok"`.
- После регистрации и перезапуска сервиса аккаунт должен сохраниться.
- Две вкладки должны видеть изменения рынка и чата без ручного обновления.

## Обновления игры

После отправки новой версии в основную ветку GitHub Railway автоматически пересоберёт сервер. Подключённый `/data` не заменяется, поэтому SQLite и прогресс сохраняются.
